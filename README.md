# STATION 07 · 第七气象站：一夜

一个原生字符画的浏览器小游戏。1961 年，东海无名礁上的第七气象站，台风正在接近。你从 23:40 接班守到天亮，每个整点做一个决定，一共有四个结局。

在线玩：https://toby-bridges.github.io/station07/

操作：按 1、2、3 或上下方向键选择，回车确认；观测时按空格快进；按 0 或 Esc 返回。目前只支持键盘。

这个仓库只放构建产物（单个 `index.html`），源码暂未公开。

字体 Station Mono 是更纱黑体 Term SC 的子集，采用 SIL Open Font License 1.1，许可证全文见 `fonts/OFL.txt`。
